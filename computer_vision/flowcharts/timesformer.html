Step 1 · Video Input
🎬
Video Frame Sampling
Extract T uniformly-spaced frames from the video
  • Input video → uniformly sample T = 8 frames
  • Each frame resized to 224 × 224 pixels
  • Dataset: subset of Kinetics-400 (~400 human action classes)
Video tensor: (B, 8, 3, 224, 224)
B = batch size, T = 8 frames, C = 3 RGB channels, H = W = 224 pixels
📐
Token Counts
How many tokens the model processes
  • Spatial tokens per frame: N = (224/16)² = 196
  • Temporal tokens: T = 8 (one per frame)
  • Total tokens: N × T + 1 = 1,569 (+ CLS token)
Token grid: (B, T+1, N, D) = (B, 9, 196, 768)
CLS token acts as "frame 0" — summarizes the entire video for classification
Patchify & embed each frame
Step 2 · Patch Embedding + Position Encoding
🧩
Patch Embedding (Conv2D)
Non-overlapping 16×16 patches → 768-dim token vectors
(B×8, 3, 224, 224) → Conv2D(3, 768, k=16, s=16) → (B×8, 768, 14, 14) → flatten + transpose → (B×8, 196, 768) → reshape → (B, 8, 196, 768)
  • Conv2D with kernel = stride = 16 → non-overlapping patch extraction
  • Each 16×16×3 patch becomes a single 768-dim embedding vector
  • Merge B and T for the convolution, then restore temporal dimension
⏱️
Temporal Position Embedding
Learnable PE along the frame axis (T+1 positions)
time_embed: (1, T+1, 1, 768)
  • Index 0 reserved for CLS token
  • Indices 1–T for actual frames
  • Broadcast across batch and spatial dimensions
📍
Spatial Position Embedding
Learnable PE along the patch axis (N positions)
space_embed: (1, 1, 196, 768)
  • Same PE shared across all frames (spatial structure is the same)
  • Added element-wise to patch tokens
  • Spatial + temporal PE combined: x + time_PE + space_PE
🔗 CLS Token Prepending

After adding position embeddings to frames 1–T, the CLS token (1, 1, 196, 768) is prepended as "frame 0" with its own temporal PE (index 0 from time_embed). Final shape: (B, T+1, N, D) = (B, 9, 196, 768)

Feed into ×12 transformer blocks
Step 3 · Divided Space-Time Attention Block (×12)
🕐
(1) Temporal Attention
Same patch, across all frames
(B, T+1, N, D) → rearrange → (B×N, T+1, D)
  • Merge batch + spatial dims → each "sequence" is T+1 frames of the same patch
  • Q, K, V all from temporal rearrangement (self-attention)
  • Each patch learns how it changes over time
  • Separate W_Q, W_K, W_V from spatial attention
(B×N, T+1, D) → MHA → (B×N, T+1, D) → rearrange back → (B, T+1, N, D)
+ residual connection + LayerNorm after attention
🗺️
(2) Spatial Attention
Same frame, across all patches
(B, T+1, N, D) → rearrange → (B×(T+1), N, D)
  • Merge batch + temporal dims → each "sequence" is N patches within one frame
  • Q, K, V all from spatial rearrangement (self-attention)
  • Each patch learns its context relative to other patches in the same frame
  • Separate W_Q, W_K, W_V from temporal attention
(B×(T+1), N, D) → MHA → (B×(T+1), N, D) → rearrange back → (B, T+1, N, D)
+ residual connection + LayerNorm after attention
⚡
(3) Feed-Forward MLP
Per-token nonlinear projection
(B, T+1, N, 768) → Linear(768, 3072) → GELU → Linear(3072, 768) → (B, T+1, N, 768)
  • Expand to 4× hidden dim then project back
  • Applied independently to every token
  • GELU activation instead of ReLU
+ residual connection + LayerNorm after MLP. This completes one block — repeat ×12.
📊 Complexity: Divided vs Joint Attention

Dividing attention into temporal + spatial steps is the key efficiency win. N = patches/frame, F = frames.

Method Per-Token Complexity Total Complexity
Joint Space-Time O(NF) O(N²F²)
Divided Space-Time (T+S) O(N + F) O(N²F + NF²)

Step 4 · Classification Head
🏷️
CLS Token → Action Class
Video-level representation → class logits
(B, T+1, N, 768) → extract x[:, 0, 0] → (B, 768) → LayerNorm → Linear(768, num_classes) → (B, num_classes)
  • CLS token is at temporal position 0, spatial position 0
  • After 12 blocks of temporal + spatial attention, CLS has aggregated information from all patches across all frames
  • Single linear layer maps to class logits (e.g., 2 classes for bench press vs. deadlift)
Compare to ground-truth label → compute loss
Step 5 · Training Loss
📉
Cross-Entropy Loss
Standard classification objective
L = −∑c yc log(pc)
  • y = one-hot ground truth label, p = softmax predictions
  • Penalizes high confidence in the wrong class
  • Standard for multi-class classification tasks
⚙️
Training Configuration
Optimizer and hyperparameters
  • Optimizer: AdamW with small learning rate
  • Backbone: ViT-Base/16 pretrained weights from timm
  • Frames: 8 (more frames → more memory, diminishing returns)
  • Batch size: 2 (limited dataset — ~80 training videos)
  • Results: ~80% at 10 epochs, ~90–92% at 30 epochs
⟲
Gradients flow end-to-end through Classification Head → 12 Transformer Blocks → Patch Embedding. Spatial attention weights are initialized from pretrained ViT-Base. Temporal attention weights are initialized from the same spatial weights (duplicated). Position embeddings and CLS token are learned from scratch.
🔄 Pretrained ViT Weight Loading

Spatial attention weights (Q, K, V projections, MLP) are copied directly from ViT-Base/16. Temporal attention weights are initialized from the same spatial weights — a form of "weight cloning" that gives temporal attention a strong starting point. The patch embedding and classification head are also transferred where dimensions match.

Design Decisions · Why?
1 Why divide attention into temporal + spatial? ▼

Joint space-time attention has O(N²F²) complexity — quadratic in both patches and frames. Divided attention reduces this to O(N²F + NF²) by attending across time and space separately. This makes longer videos and higher resolutions feasible. Joint attention goes OOM at ~96 frames; divided stays tractable.

2 Why does divided beat joint despite seeing less context? ▼

Divided attention has separate learnable parameters for temporal and spatial attention (2× the Q, K, V projections). Joint uses one shared set for everything. The specialization — temporal heads learn motion, spatial heads learn appearance — more than compensates for the reduced attention window. Paper result: 78.0% vs 77.4% top-1 on Kinetics-400.

3 Why use separate position embeddings for space and time? ▼

Spatial and temporal structure are fundamentally different. Spatial PE encodes where a patch is in the 14×14 grid — the same across all frames. Temporal PE encodes which frame it is — the same for all patches within a frame. Separating them gives the model clearer positional signals than a single flattened PE would.

4 Why only 8 frames? ▼

Memory scales linearly with frames, and attention scales quadratically (even divided). At 8 frames, the total token count is 1,569. At 32 frames it becomes 6,273 — approaching GPU memory limits. The paper shows diminishing accuracy gains beyond 8–16 frames for most Kinetics actions, which are short (~8–10s) clips.

5 Why initialize temporal weights from spatial? ▼

ViT was pretrained on images — it has no temporal weights. Instead of random initialization, cloning spatial weights into temporal gives the temporal branch a strong starting point: general feature extraction patterns. During finetuning, temporal weights diverge to specialize in motion patterns while spatial weights stay closer to the original ViT.

6 The mental model that makes TimeSformer click ▼

Think of each patch as living in a space-time grid. Temporal attention lets patch (3, 7) — row 3, col 7 — "talk" to itself across all 8 frames ("am I moving?"). Spatial attention lets it talk to all 196 patches in the same frame ("what's around me?"). After 12 rounds of both, the CLS token has a complete picture of what happened where and when.
